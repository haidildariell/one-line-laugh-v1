# One-Line Laugh — v1

A single original one-liner for the make.fun bounty **"The One-Line Laugh"**: one funny line, one sentence, under 200 characters, with the surprise saved for the very end.

Running `main.py` writes the line to `/output/entry.txt` — nothing else, no trailing newline.
